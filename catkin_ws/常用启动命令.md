# 常用启动命令

这份文档只保留当前最常用、最直接的命令。

## 1. `sh` 脚本怎么运行

### 第一次运行前，先给脚本执行权限
```bash
chmod +x ~/catkin_ws/tools/start_uav_stack.sh
```

说明：
- 一般只需要执行一次
- 只有在你重新覆盖了脚本、权限被改掉、或者换了新文件时，才需要再执行一次

### 最常用的运行方式
```bash
bash ~/catkin_ws/tools/start_uav_stack.sh
```

### 另一种运行方式
```bash
cd ~/catkin_ws/tools
./start_uav_stack.sh
```

说明：
- `bash xxx.sh` 不依赖文件本身有没有执行权限，最稳
- `./start_uav_stack.sh` 需要先 `chmod +x`
- 这个脚本建议在 **NX 的 NoMachine 图形终端** 里运行
- 不建议在纯 SSH 终端里直接运行，因为它要拉起图形终端和 RViz

## 2. 手动按顺序启动四个终端

### 终端 1：启动 MAVROS
```bash
source /opt/ros/noetic/setup.bash
roslaunch mavros px4.launch fcu_url:=/dev/ttyACM0:57600
```

### 终端 2：启动 Livox MID360 驱动
```bash
source /opt/ros/noetic/setup.bash
source ~/livox_ws/devel/setup.bash
roslaunch livox_ros_driver2 msg_MID360.launch
```

### 终端 3：启动 FAST-LIO2
```bash
source /opt/ros/noetic/setup.bash
source ~/livox_ws/devel/setup.bash
source ~/fast_lio2_ws/devel/setup.bash
roslaunch fast_lio mapping_mid360.launch
```

### 终端 4：启动桥接脚本
```bash
source /opt/ros/noetic/setup.bash
source ~/catkin_ws/devel/setup.bash
python3 ~/catkin_ws/src/fastlio_to_mavros/scripts/fastlio_mavros_bridge.py
```

## 3. 只启动桥接节点

```bash
source /opt/ros/noetic/setup.bash
source ~/catkin_ws/devel/setup.bash
roslaunch fastlio_to_mavros bridge_only.launch
```

如果你想测试速度话题：

```bash
source /opt/ros/noetic/setup.bash
source ~/catkin_ws/devel/setup.bash
roslaunch fastlio_to_mavros bridge_only.launch publish_speed:=true
```

提醒：
- 第一次恢复试飞，建议先保持默认的 `false`

## 4. 本地改完以后，把代码推回 NX

### 推荐方式：用指定 IP 的同步脚本
在 Windows PowerShell 里执行：

```powershell
powershell -ExecutionPolicy Bypass -File "D:\repos\slam-drone\catkin_ws\tools\sync_to_nx.ps1" -NxHost 你的NX热点IP
```

### 手动推整个包
```powershell
ssh password123456@你的NX热点IP "mkdir -p ~/catkin_ws/src ~/catkin_ws/tools"
scp -r "D:/repos/slam-drone/catkin_ws/src/fastlio_to_mavros" password123456@你的NX热点IP:~/catkin_ws/src/
scp "D:/repos/slam-drone/catkin_ws/tools/start_uav_stack.sh" password123456@你的NX热点IP:~/catkin_ws/tools/
```

## 5. 改完以后要不要重新编译

### 不用重新编译的情况
- 只改了 `.py`
- 只改了 `.launch`
- 只改了 `.yaml`

这时一般只要重新 `source`，然后重启节点：

```bash
source ~/catkin_ws/devel/setup.bash
```

### 需要重新编译的情况
- 改了 `CMakeLists.txt`
- 改了 `package.xml`
- 改了 C++ 源码

命令：

```bash
cd ~/catkin_ws
catkin_make
source ~/catkin_ws/devel/setup.bash
```

## 6. 试飞前提醒
- 先连 NoMachine，再插雷达网口
- 如果实验室路由器一插雷达就掉线，优先改用手机热点做 SSH / NoMachine
- 先确认地面站里能看到飞行模式和连接状态
- 先用绳子或其他限位方式拴住飞机
- 先低风险验证位姿是否稳定，再谈定点性能
