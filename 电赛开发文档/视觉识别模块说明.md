## 2. 当前第一阶段

在机载电脑创建 ROS1 包：

```text
/home/password123456/catkin_ws/src/d2026_vision
```

完成：

- D435i RGB 与 CameraInfo 订阅；

- 发布调试图、ID 列表和相机系 PoseArray。

第一阶段不做平台中心融合、飞机中心补偿、伴飞或降落控制。

## 3. 后续测量

Tag 粘贴完成后，需要记录：

```text
每个 Tag ID
Tag 实际检测边长
Tag 中心相对靶标中心的 x/y/z
Tag 相对小车车头的旋转方向
```

相机安装完成后，需要记录：

```text
相机相对飞机中心向前偏移多少厘米
相机相对飞机中心向左/右偏移
相机相对飞机中心向下偏移
相机下视安装的 roll/pitch/yaw 外参
```

这些数据必须通过刚体变换/TF 使用，不能只在相机光学坐标的某一轴上简单减一个数。

## 4. 安全边界

视觉包禁止：

- 发布 MAVROS setpoint；
- 解锁或切换模式；
- 调用起飞和降落；
- 修改 `px4_basic_control`；
- 修改 FAST-LIO2、MAVROS 或 PX4 参数。

联调顺序：单 Tag 地面测试 → 不同尺寸距离校验 → Tag 粘贴位置实测 → 平台中心解算 → 相机外参 → 悬停只观察 → 限速伴飞 → 最后动态降落。
