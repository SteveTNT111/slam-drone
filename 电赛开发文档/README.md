## 1. 题目核心要求摘要

### 1.1 系统组成

系统由三部分组成：

1. 多旋翼飞行器；
2. 轮式循线小车；
3. 无线通信地面站。

飞行器需要实现：自动起飞、室内定位/悬停、跟踪小车、物资抛投、返回起降点降落；第二阶段冲刺动态降落到小车平台，再起飞返航。

小车需要实现：一键启动、从 A 点出发、顺时针循黑色轨迹行走一圈、全程不得停车、回到 A 点后自动停止，并向无人机发送启动指令。

地面站需要实现：图形化实时显示无人机和小车在场地内的位置，文字显示无人机实时状态，例如伴飞、抛投、降落、起飞等；显示屏尺寸不小于 6 英寸；测评时禁止联网、禁止现场改代码。

### 1.2 关键约束

| 项目 | 约束 |
|---|---|
| 场地大小 | 400 cm × 500 cm |
| 起降点 | H 点 |
| 小车起点/终点 | A 点 |
| 小车轨迹 | 黑色闭合线，顺时针行进 |
| 黑线宽度 | 2 cm ± 0.2 cm |
| 无人机起飞高度 | 150 ± 10 cm |
| 起飞后悬停 | 稳定悬停 3 秒 |
| 抛投物 | 25 ± 5 g 软质物体 |
| 小车总时间 | 每次任务一圈 ≤ 90 秒 |
| 动态任务 B 点 | 小车启动后 15 秒内到 B 点 |
| 平台尺寸 | 不超过 60 cm × 60 cm |
| 平台图案 | 直径 30 cm、50 cm 同心圆环 + 十字，线宽 2 cm ± 0.2 cm |
| 无人机轴距 | 最大轴间距不大于 45 cm |
| 桨叶保护 | 必须全防护 |

## 2. 当前最重要的规则解释和疑问结论

### 2.1 能否比赛开始前就让无人机悬停在小车上方？

**不建议，也大概率不符合题意。**

题目要求是：小车一键启动，小车启动时发送无线指令，使无人机在起降点自动垂直起飞，升至 150±10 cm 高度悬停 3 秒；随后飞至小车上方，并在小车到达 B 点前形成伴飞状态。

所以更稳的合法流程是：

```text
小车按键启动
  -> 小车立刻发 START 给无人机
  -> 小车开始循线慢速前进
  -> 无人机从 H 点起飞到 1.5 m
  -> 悬停 3 s
  -> 无人机飞到小车上方
  -> 在 B 点前锁定平台图案并进入伴飞
```

### 2.2 能否先让无人机飞到小车上方，再跟随小车一起移动？

**可以作为主策略，但必须发生在小车启动之后，且在小车到达 B 点前形成伴飞。**

这比“在空中远距离搜索高速移动小车”更稳。建议小车在 A 到 B 段采用可控速度，让无人机有足够时间完成起飞、悬停、横移和视觉锁定。

### 2.3 抛投能否在小车静止时完成？

**不能作为正式方案。**

题目明确写了“小车行进过程中不得停车”，并且抛投要求是“伴飞期间”“小车行走至 D 点前完成”。所以正式测试应按“车在行进中、无人机在伴飞中抛投”设计。

静止抛投只能用于调试标定，不应作为最终策略。

### 2.4 抛投时无人机能否下降高度？

题目没有单独给“抛投高度”，但第 1 项写了无人机升至 150±10 cm 后“保持巡航高度”飞至小车上方，第 1.3 项又写“以巡航高度返回起降点”。因此保守理解：**巡航、伴飞、抛投高度应保持约 1.5 m。**

建议正式策略：

- 高度设定 1.45 m 到 1.50 m；
- 抛投物使用软质、低弹跳、略带粘性或能量耗散结构，例如橡皮泥包裹软物、软布袋加橡皮泥底；
- 设计垂直导向释放机构，减少初始水平速度；
- 用视觉提前量补偿小车运动。

如果想在抛投瞬间下降到 1.2 m 或更低，必须赛前向裁判确认，否则有丢分风险。

### 2.5 动态降落是否必须在小车运动中完成？

**是。**

题目说明“无人机成功降落在小车平台上”指最终稳定停留在小车平台 5 秒以上，同时小车正常行进。也就是说动态降落任务不是“车停下接飞机”。

### 阶段 A：保底可演示

小车能跑一圈，无人机能室内定位、起飞、悬停、返航降落，地面站能显示状态。

### 阶段 B：拿下抛投任务 60 分

小车启动后，无人机自动起飞，B 点前进入伴飞，D 点前完成运动中抛投，之后返航降落，小车回 A 停车，全程 90 秒内。

### 阶段 C：冲刺动态起降 20 分

小车运动中，无人机识别平台，降落并稳定停留 5 秒，再起飞返航。

## 5. 系统模块拆解

### M1 小车循线模块

状态机：

```text
IDLE
  -> BUTTON_PRESSED
  -> SEND_UAV_START
  -> LINE_FOLLOW
  -> DETECT_A_RETURN
  -> STOP
```

必须完成：

- [ ] 按键启动；
- [ ] 顺时针循线；
- [ ] 一圈内不停车；
- [ ] 回 A 后自动停；
- [ ] 总时间 ≤ 90 秒。

### M2 无线通信模块

最低消息：

| 消息 | 方向 | 含义 |
|---|---|---|
| `CAR_START` | 小车 -> 无人机/地面站 | 小车启动，无人机起飞 |
| `CAR_STATE` | 小车 -> 地面站 | 小车运行、停止、错误 |
| `UAV_STATE` | 无人机 -> 地面站 | 起飞、悬停、伴飞、抛投、返航、降落 |
| `DROP_DONE` | 无人机 -> 地面站/小车 | 抛投完成 |
| `EMERGENCY` | 任意 -> 地面站 | 异常或急停 |

### M3 无人机室内定位模块

当前路线：

```text
MID360 -> livox_ros_driver2 -> FAST-LIO2 -> /Odometry
/Odometry -> fastlio_to_mavros -> /mavros/vision_pose/pose
PX4 EKF2 -> /mavros/local_position/pose
```

比赛前必须验证：

```bash
rostopic hz /Odometry
rostopic hz /mavros/vision_pose/pose
rostopic hz /mavros/local_position/pose
rostopic echo /Odometry
rostopic echo /mavros/vision_pose/pose
rostopic echo /mavros/local_position/pose
```

判断标准：

- 静止时 xyz 不持续漂移；
- 抬高飞机时 z 方向正确；
- 移动后放回，位置能大致回到原位；
- PX4 能进入 Position/Altitude 类悬停模式。

### M4 无人机基础飞行模块

先做最短链路：

```text
起飞点 H
  -> 垂直起飞到 1.5 m
  -> 悬停 3 s
  -> 定点悬停 30-60 s
  -> 回 H 上方
  -> LAND
```

### M5 小车平台视觉识别模块

第一版算法：

1. 图像灰度化；
2. 阈值分割黑色线条；
3. 找轮廓；
4. 找同心圆/椭圆；
5. 找十字交点；
6. 融合圆心和十字中心；
7. 输出中心偏差。

### M6 伴飞控制模块

主策略：视觉伺服，而不是远距离追移动目标。

```text
如果 target_visible:
    根据图像中心偏差控制 vx, vy
    高度保持 1.5 m
    yaw 保持与小车方向或场地坐标近似一致
else:
    保持当前速度/短时预测
    超过 timeout 则悬停或进入安全策略
```

### M7 抛投模块

抛投要求：

- 物体 25±5 g；
- 软质；
- 最终稳定停留在小车平台表面的黑色圈内；
- 伴飞期间完成；
- 小车到 D 点前完成。

### M8 返航降落模块

保守策略：

```text
抛投完成
  -> 保持 1.5 m 巡航高度
  -> 飞回 H 点上方
  -> 切 LAND 或 px4ctrl_land
```

### M9 动态降落模块（第二阶段）

高风险模块，只有在 M3-M8 稳定后再冲刺。

## 7. 联调顺序

1. 小车单独跑：按键后小车跑一圈回 A 停止。
2. 无人机单独定点：1.5 m 悬停稳定，能返航降落。
3. 无线启动联调：按小车按钮后，无人机收到 `CAR_START`。
4. 静止平台视觉识别：无人机悬停在静止小车上方，OpenCV 稳定输出中心偏差。
5. 低速伴飞：小车低速移动，无人机在平台上方跟随，不抛投。
6. 静止抛投标定：只用于调试，不作为正式任务。
7. 运动中抛投：小车运动中，D 点前抛投物最终停在黑圈内。
8. 完整抛投任务：90 秒内完成全部流程。
9. 动态起降冲刺：小车运动中降落到平台，稳定 5 秒，再起飞返航。

## 9. 风险清单

| 风险 | 后果 | 缓解 |
|---|---|---|
| 室内定位漂移 | 无法悬停/返航 | 先定点，不急着伴飞；录 bag 查 `/Odometry`、`/vision_pose`、`/local_position` |
| Pixhawk 4 输出配置不稳 | 电机异常 | 拆桨验证 M1-M4、旋向、DShot/PWM 配置 |
| 小车跑太快 | B 前无法伴飞 | 小车 A-B 段限速，先低速伴飞 |
| 视觉识别受光照影响 | 跟踪丢失 | 多光照测试，阈值自适应，增加置信度和丢失保护 |
| 抛投物弹出平台 | 抛投不得分 | 低弹跳软物、橡皮泥、导向筒、提前量补偿 |
| 地面站联网或现场改代码 | 作弊风险 | 赛前封箱，离线运行，所有参数提前固化 |

## 11. 当前推荐结论

1. **先不要纠结动态降落，先把无人机室内定点恢复。** 没有稳定室内定位，后面的伴飞、抛投、动态起降都做不了。
2. **小车先独立完成“按键启动、循线一圈、回 A 停车”。** 这是整个题目的地面底座。
3. **无人机跟踪策略采用“先飞到小车上方再视觉伺服跟随”。** 不要做复杂的远距离搜索移动小车。
4. **正式抛投必须在小车运动中完成。** 静止抛投只用于调试。
5. **抛投高度保守按 1.5 m 巡航高度做。** 降低高度需问裁判，否则可能被认为不保持巡航高度。
6. **地面站和报告不要最后一天才做。** 这两项分数相对稳定，应该并行推进。
