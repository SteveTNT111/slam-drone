# 视觉识别模块说明

## 1. 目标

用无人机下视摄像头识别小车平台中心图案，输出平台中心相对图像中心的偏差，用于伴飞和抛投。

平台图案：

- 直径 30 cm 黑色圆环；
- 直径 50 cm 黑色圆环；
- 中心十字；
- 线宽 2 cm ± 0.2 cm。

## 2. 输入输出

输入：

```text
/camera/image_raw
无人机高度 z
可选：相机内参
```

输出：

```text
target_visible
center_x_px
center_y_px
cx_error_px
cy_error_px
confidence
```

## 3. 第一版 OpenCV 流程

```text
BGR/RGB 图像
  -> 灰度化
  -> 自适应阈值或 HSV 黑色分割
  -> 形态学开闭运算
  -> 找轮廓
  -> 筛选近似圆/椭圆轮廓
  -> 找同心结构
  -> 找十字线交点
  -> 融合中心点
  -> 输出偏差和置信度
```

## 4. 置信度建议

置信度可以由以下因素组成：

- 是否同时看到两个圆环；
- 两个圆心距离是否足够接近；
- 圆环直径比例是否接近 50:30；
- 是否检测到十字；
- 图案面积是否符合当前高度下的预期范围；
- 最近几帧中心是否连续。

## 5. 调试数据集

必须拍：

- [ ] 室内强光；
- [ ] 室内弱光；
- [ ] 有阴影；
- [ ] 倾斜角度；
- [ ] 1.5 m 高度；
- [ ] 1.2 m 高度；
- [ ] 小车运动模糊；
- [ ] 平台局部遮挡。

## 6. 给飞控的控制意义

图像中心偏差转换为速度控制：

```text
vx = k_y * cy_error_px
vy = k_x * cx_error_px
```

注意实际方向取决于相机安装方向和 ROS 坐标系，必须实测确认正负号。

## 7. 失败保护

| 情况 | 处理 |
|---|---|
| 丢失 < 0.5 秒 | 保持上一速度或短时预测 |
| 丢失 0.5-2 秒 | 减速悬停，扩大搜索 |
| 丢失 > 2 秒 | 放弃抛投，返航或等待人工接管 |
| 置信度跳变 | 不触发抛投 |
| 中心误差过大 | 只跟随，不抛投 |
