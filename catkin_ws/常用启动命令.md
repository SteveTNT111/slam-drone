# 常用启动命令

这份文档只放当前这套飞机最常用的命令：室内定位栈、EGO 导航栈、px4ctrl 起飞/降落、录包和排障。默认运行位置是 NX 的 NoMachine 图形桌面终端。

## 1. 当前结论

- `ego_planner/launch/single_run_in_fastlio.launch` 已经切到 FAST-LIO2：里程计订阅 `/Odometry`，点云订阅 `/cloud_registered`，深度图输入被设成 `nouse_depth`。
- `tools/start_planner_stack.sh` 会启动 `px4ctrl`、`ego_planner single_run_in_fastlio.launch` 和 RViz；它不会自动起飞。
- `px4ctrl` 当前控制配置是 `src/px4ctrl/config/ctrl_param_fpv.yaml`，其中 `mass: 1.2`、`hover_percentage: 0.30`、起飞高度 `1.0 m`。
- 目前这版 px4ctrl 主控制里的简化油门映射直接使用 `hover_percentage` 初始化 `thr2acc`，`mass` 在当前主控制计算里不是最直接的危险项；但重量仍然应该在电子秤恢复后改准，尤其以后打开精确推力模型或做油门标定时会用到。
- 如果现在没法称重，最应该保守看待的是 `hover_percentage`：它不准会直接影响悬停油门和高度响应。第一次自由飞前建议先做拴绳/手持/低高度测试，不要直接大范围规划。

## 2. 一键推荐流程

第一次覆盖脚本后，先给工具目录里的脚本执行权限：

```bash
chmod +x ~/catkin_ws/tools/*.sh
```

启动室内定位底座：

```bash
bash ~/catkin_ws/tools/start_uav_stack.sh
```

这个脚本会弹出 7 个窗口：`mavros`、`livox`、`fastlio`、`bridge`、`monitor_debug`、`monitor_hz`、`record_bag`。它负责让 FAST-LIO2 位姿经过桥接脚本送到 MAVROS/PX4，用于室内定点。

确认定位和飞控链路正常：

```bash
rostopic hz /Odometry /cloud_registered /mavros/vision_pose/pose /mavros/local_position/pose
rostopic echo -n 1 /mavros/state
```

启动 EGO 导航和 px4ctrl：

```bash
bash ~/catkin_ws/tools/start_planner_stack.sh
```

它会弹出 3 个窗口：`px4ctrl_fastlio`、`ego_planner_fastlio`、`ego_rviz`。到这一步还没有起飞，只是控制器、规划器和 RViz 已经准备好。

确认遥控器开关、油门/横滚/俯仰/偏航杆居中，确认定位稳定后，再执行起飞：

```bash
bash ~/catkin_ws/tools/px4ctrl_takeoff.sh
```

起飞命令只做一件事：向 `/px4ctrl/takeoff_land` 发布 `takeoff_land_cmd: 1`。px4ctrl 收到后会从 `MANUAL_CTRL` 进入 `AUTO_TAKEOFF`，调用 MAVROS 的 `/mavros/set_mode` 请求 PX4 进入 `OFFBOARD`，如果配置允许自动解锁，还会调用解锁服务。PX4 是否接受 OFFBOARD/ARM，仍取决于飞控状态、遥控器状态、定位质量和 PX4 参数。

飞机到达配置的起飞高度后，px4ctrl 会进入 `AUTO_HOVER`。这时在 RViz 里按 `G` 或使用 `2D Nav Goal` 选点，RViz 会发布 `/move_base_simple/goal`，EGO-Planner 收到目标点后规划轨迹，`traj_server` 发布 `/position_cmd`，px4ctrl 在 `AUTO_HOVER` 收到命令后进入 `CMD_CTRL` 跟踪轨迹。

降落：

```bash
bash ~/catkin_ws/tools/px4ctrl_land.sh
```

降落命令向 `/px4ctrl/takeoff_land` 发布 `takeoff_land_cmd: 2`。px4ctrl 要求降落命令从 `AUTO_HOVER` 触发；如果正在 `CMD_CTRL` 跟踪轨迹，应先停止继续发送目标点，等 `/position_cmd` 超时后回到 `AUTO_HOVER`，再降落。

## 3. NX 桌面一键入口

这些 `.desktop` 文件放在 `~/catkin_ws/tools` 后，可以复制到桌面双击使用：

```bash
cp ~/catkin_ws/tools/nx_one_click_*.desktop ~/Desktop/
chmod +x ~/catkin_ws/tools/*.sh ~/catkin_ws/tools/*.desktop ~/Desktop/nx_one_click_*.desktop
```

| 桌面文件 | 作用 | 等价命令 |
| --- | --- | --- |
| `nx_one_click_start.desktop` | 一键启动室内定位底座 | `bash ~/catkin_ws/tools/start_uav_stack.sh` |
| `nx_one_click_ego_navigation.desktop` | 一键启动 EGO 导航栈 | `bash ~/catkin_ws/tools/start_planner_stack.sh` |
| `nx_one_click_px4ctrl_takeoff.desktop` | 一键发送 px4ctrl 起飞命令 | `bash ~/catkin_ws/tools/px4ctrl_takeoff.sh` |
| `nx_one_click_px4ctrl_land.desktop` | 一键发送 px4ctrl 降落命令 | `bash ~/catkin_ws/tools/px4ctrl_land.sh` |

对应的包装脚本是：

```bash
bash ~/catkin_ws/tools/nx_one_click_start.sh
bash ~/catkin_ws/tools/nx_one_click_ego_navigation.sh
bash ~/catkin_ws/tools/nx_one_click_px4ctrl_takeoff.sh
bash ~/catkin_ws/tools/nx_one_click_px4ctrl_land.sh
```

起飞和降落桌面入口会打开一个终端窗口，先显示倒计时提示，再发送命令。误点时可以在倒计时内按 `Ctrl+C` 取消。

## 5. 手动分窗口启动室内定位底座

如果一键脚本打不开图形终端，可以手动开 4 个终端：

终端 1：MAVROS

```bash
source /opt/ros/noetic/setup.bash
roslaunch mavros px4.launch fcu_url:=/dev/ttyACM0:57600
```

终端 2：Livox MID360 驱动

```bash
source /opt/ros/noetic/setup.bash
source ~/livox_ws/devel/setup.bash
roslaunch livox_ros_driver2 msg_MID360.launch
```

终端 3：FAST-LIO2

```bash
source /opt/ros/noetic/setup.bash
source ~/livox_ws/devel/setup.bash
source ~/fast_lio2_ws/devel/setup.bash
roslaunch fast_lio mapping_mid360.launch
```

终端 4：FAST-LIO2 到 MAVROS 桥接

```bash
source /opt/ros/noetic/setup.bash
source ~/catkin_ws/devel/setup.bash
python3 ~/catkin_ws/src/fastlio_to_mavros/scripts/fastlio_mavros_bridge.py
```

只启动桥接节点：

```bash
source /opt/ros/noetic/setup.bash
source ~/catkin_ws/devel/setup.bash
roslaunch fastlio_to_mavros bridge_only.launch
```

测试速度话题时再打开：

```bash
roslaunch fastlio_to_mavros bridge_only.launch publish_speed:=true
```

第一次恢复试飞，建议先保持默认的 `publish_speed:=false`。

## 7. 改完要不要重新编译

不用重新编译的情况：

- 只改 `.sh`
- 只改 `.desktop`
- 只改 `.md`
- 只改 `.py`
- 只改 `.launch`
- 只改 `.yaml`

这时重启对应节点即可。

需要重新编译的情况：

- 改了 `CMakeLists.txt`
- 改了 `package.xml`
- 改了 C++ 源码
- 改了 ROS 消息 `.msg`

命令：

```bash
cd ~/catkin_ws
catkin_make
source ~/catkin_ws/devel/setup.bash
```

## 8. 试飞前提醒

- 先连 NoMachine，再插雷达网口。
- 先确认地面站能看到飞控连接、飞行模式、解锁状态。
- 起飞前确认 `/Odometry`、`/mavros/vision_pose/pose`、`/mavros/local_position/pose` 都稳定。
- 先用低风险方式验证定位、桥接、OFFBOARD、px4ctrl 悬停，再选远目标点。
- 电子秤没电时，可以先不改 `mass` 做地面链路测试；自由飞前要尽量补称重量，并认真确认 `hover_percentage`。
- 遥控器必须保留手动介入能力，紧急情况优先切回手动/姿态/定高一类人工可控模式。

## 9. 录包与拉包

轻量录包：

```bash
bash ~/catkin_ws/tools/record_flight_debug.sh light
```

完整录包：

```bash
bash ~/catkin_ws/tools/record_flight_debug.sh full
```

一键启动室内定位底座时，`start_uav_stack.sh` 默认会自动打开一个 `full` 模式录包窗口：

```bash
bash ~/catkin_ws/tools/start_uav_stack.sh
```

停止录包：在录包终端按 `Ctrl+C`。

录包文件在 NX 上的位置：

```bash
~/catkin_ws/rosbags
```

抽取最新 bag：

```bash
bash ~/catkin_ws/tools/extract_flight_debug.sh latest
```

从个人计算机拉回录包：

```powershell
scp -r password123456@你的NX热点IP:~/catkin_ws/rosbags "D:/repos/slam-drone/catkin_ws/"
```
