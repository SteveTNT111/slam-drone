# 临时开发文档

这份文档只记录**当前这一轮开发**最直接可用的命令。

当前约定：

- NX 当前热点 IP：`10.234.68.127`
- 当前做法：**本地代码仓库负责版本管理**
- 当前上传方式：**把整个 `fastlio_to_mavros` 包原样上传到 NX 工作空间**
- NX 上只保留最新版可运行代码

如果 NX 的热点 IP 以后变了，只需要把下面命令里的：

```text
10.234.68.127
```

替换成新的 IP。

---

## 1. 先测试 SSH 是否打通

在个人计算机的 PowerShell 里执行：

```powershell
ssh password123456@10.234.68.127 "echo SSH_OK"
```

如果输出：

```text
SSH_OK
```

说明当前 SSH 是通的。

```powershell
ssh password123456@10.234.68.127 "mkdir -p ~/catkin_ws/src ~/catkin_ws/tools"
```

- 确保 `catkin_ws/src`
- 确保 `catkin_ws/tools`

## 8. 上传完成后，在 NX 上补执行权限

在 NX 终端里执行：

```bash
chmod +x ~/catkin_ws/tools/start_uav_stack.sh
chmod +x ~/catkin_ws/src/fastlio_to_mavros/scripts/fastlio_mavros_bridge.py
```

说明：

- `start_uav_stack.sh` 如果重新覆盖过，最好再补一次权限
- 桥接脚本如果重新覆盖过，也顺手补一次权限

## 9. 桥接脚本手动启动命令

在 NX 终端里执行：

```bash
source /opt/ros/noetic/setup.bash
source ~/catkin_ws/devel/setup.bash
python3 ~/catkin_ws/src/fastlio_to_mavros/scripts/fastlio_mavros_bridge.py
```

---

## 10. 一键启动脚本运行命令

在 NX 的 NoMachine 图形终端里执行：

```bash
bash ~/catkin_ws/tools/start_uav_stack.sh
```

如果 NX 上装了 `terminator`，也可以这样：

```bash
TERMINAL_BIN=terminator bash ~/catkin_ws/tools/start_uav_stack.sh
```

---

## 11. 当前这套开发方式的核心规则

### NX 上

- 只放最新版
- 直接覆盖运行

### 本地仓库上

- 用 Git 管版本
- 稳定版本就 `commit`
- 更稳定的版本可以 `tag`

也就是说：

- **NX 负责运行**
- **本地仓库负责历史**
