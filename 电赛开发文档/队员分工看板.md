# 队员分工看板

## 队员 A：无人机飞控/定位/安全

### 今天必须交付

- [ ] Pixhawk 4 参数备份；
- [ ] 电机编号和旋向确认；
- [ ] 室内定位链路启动成功；
- [ ] PX4 本地位置稳定；
- [ ] 低高度悬停 30 秒；
- [ ] 一键返航/降落初版。

### 明确接口

输出给队员 C/地面站：

```text
uav_state: IDLE/TAKEOFF/HOVER/FOLLOW/DROP/RETURN/LAND/DONE/ERROR
uav_x_cm, uav_y_cm, uav_z_cm
uav_yaw_deg
tracking_target_visible
```

接收队员 C/视觉：

```text
target_visible
cx_error_px
cy_error_px
confidence
```

接收队员 B/小车：

```text
CAR_START
car_state
可选 car_progress_percent
```

### 禁止事项

- 定位漂移时禁止 OFFBOARD；
- 未拆桨禁止电机测试；
- 伴飞没稳定前禁止抛投；
- 遥控器不能接管时禁止继续试飞。

## 队员 B：TI 小车/循线/平台

### 今天必须交付

- [ ] 黑线场地；
- [ ] 按键启动；
- [ ] 顺时针循线；
- [ ] 回 A 自动停；
- [ ] 一圈时间记录；
- [ ] 无线发送 `CAR_START`；
- [ ] 车顶平台安装牢固。

### 小车速度档位建议

| 档位 | 用途 | 说明 |
|---|---|---|
| slow | 伴飞初调 | 给无人机足够时间锁定平台 |
| normal | 抛投任务 | 90 秒内稳定跑完 |
| fast-B | 动态起降任务 | 15 秒内到 B 点 |

### 明确接口

输出给无人机/地面站：

```text
CAR_START
car_state: IDLE/RUNNING/AT_B/AT_C/AT_D/FINISHED/ERROR
car_progress_percent
car_speed_level
```

最低要求：即使没有精确位置，也要能发 `CAR_START` 和 `FINISHED`。

### 禁止事项

- 正式任务中不得停车；
- 不要为了等无人机而让小车停在 A-B 段；
- 平台面积不得超过 60 cm × 60 cm；
- 平台图案中心不要被机构遮挡。
